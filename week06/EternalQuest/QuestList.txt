Quests

tutorial
    * criar conta sud
    * criar conta familysearch
    * adicionar data de batismo e confirmação
    * adicionar horario da Sacramental
    * working?


simples
    * aprender a dar o dizimo online
    * Conseguir um chamado ou designação
    * Incluir suas proprias informações no familysearch
    * Incluir informações dos pais no familysearch
    * Incluir informações dos avós no familysearch
    * Incluir informações dos bisavós no familysearch
    * Dar ao menos uma referencia para os missionários
    * Obter recomendação de tempo limitado para o templo
    * Aceitar fazer um discurso quando convidado
    * Se não tirou a benção patriarcal:
        -> tirar a benção patriarcal
    * Preparar uma reunião familiar.

checklist
    * Levar (n) nomes para o templo para {ordenança} no templo
    * Ir ao templo n vezes ao mes fazer ordenanças 
    * Realizar trabalho de ministração pelo menos 4 vezes por mes
    * Ler (n) discurso(s) da conferencia por mes
    * Se tem benção patriarcal
        -> estudar a benção patriarcal 1 vez ao mes

eternal quests (repete num dado periodo de tempo)
    * pagar o dizimo e dar ofertas
    * estudar as escrituras (n) min por dia
    * Tomar o sacramento
    * Fazer indexação n horas semanais
    * se tem chamado
        -> Trabalhar no chamado n horas semanais
    * Buscar informações familiares e colocar no family search
    * Ir ao templo fazer ordenanças n vezes ao mes
    * Realizar trabalho de ministração pelo menos 4 vezes por mes
    * Fazer jejum pelo menos 1 vez ao mes
    * Orar ao acordar e dormir;
    * Orar antes das refeições

timeQuest
    * Se tem recomendação para o templo e proximo da validade:
        -> iniciar a quest de marcar entrevista para renovar recomendação
    * Se chamado para discursar 
        -> quest na semana de preparar o discurso com antecedência
    se batizado, mas com ~1 anos de membro
        -> obter recomendação completa para investidura
    * Por idade 
        -> Seminário: 14-17
            -> Frequentar o seminário
            -> Força dos jovens
            -> Decorar o tema (Rapazes/Moças)
            -> Participar atividades (OR/OM/ORM)
                -> se menino
                    pedir entrevistas para avançar no sacerdócio

        -> Instituto: 18-35
            -> Frequentar o Instituto
            -> níveis do Instituto
            -> Participar atividades JAS

Custom
    * Usuário entra com uma quest, tipo, dificuldade, (se quiser um prazo)
